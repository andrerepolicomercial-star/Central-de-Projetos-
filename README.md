# DM Field BAND — versão original restaurada

Aplicativo recuperado do arquivo index(10).html da biblioteca, com 347 clientes de 6 desenvolvedores incorporados ao código, layout e funcionalidades originais.

## Instalação
Envie os cinco arquivos da pasta para a raiz do repositório GitHub. Em Settings > Pages, configure main e / (root). Abra a URL publicada no Chrome e use Instalar aplicativo.

## Atenção
Os registros de visitas anteriores armazenados no navegador não estão incluídos. Para restaurá-los é necessário um backup JSON. Faça backups periódicos.
