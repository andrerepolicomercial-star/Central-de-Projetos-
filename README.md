# DM Field BAND

Aplicativo instalável no Chrome para gestão de rotas e atendimentos B2B.

## Publicação
1. Crie um repositório público no GitHub (ou use um existente).
2. Envie **todos os arquivos desta pasta diretamente para a raiz do repositório**. Não envie somente o ZIP e não coloque os arquivos dentro de uma subpasta.
3. Vá em **Settings > Pages > Build and deployment** e escolha **Deploy from a branch**, branch **main**, pasta **/(root)**. Salve.
4. Abra o endereço do GitHub Pages. No Chrome Android, abra o menu de três pontos e selecione **Instalar aplicativo** ou **Adicionar à tela inicial**.

## Dados
O app começa sem clientes cadastrados. Cadastre-os manualmente ou importe uma lista com linhas no formato `Desenvolvedor;Número;Código;Nome;Endereço`. Os dias são organizados por posição: 1–19, 20–38 e 39–58. Exporte backup JSON regularmente em **Dados e backup**. Dados locais apagados do navegador não podem ser recuperados sem backup.
